# PS3ME 01.16

Install `PS3ME_PS3_01.16.pkg` over your existing installation. Title ID remains
`PS3ME0001`; existing games, RMS saves and control profiles keep their paths.
No games or test JARs are bundled.

Bounce Tales' unmodified supplied JAR now reaches the menu and Chapter 1 gameplay
in RPCS3 after restoring missing Nokia platform classes. Nokia Sound and MMAPI
tone support are restored, with additional pixel-alignment and packaging checks.
The existing MP3 worker, audio budgets, controls, touchscreen, profiles,
resolutions, UI and 01.15 loading optimizations remain.

01.16 has not been verified on a physical PS3. The port remains experimental.
See `RELEASE_NOTES_01.16.md`, `docs/COMPATIBILITY_AUDIT_01.16.md` and the main README
for validation, controls, game locations, limitations, credits and source details.
