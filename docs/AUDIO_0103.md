# Audio 01.03

Implemented: Manager.createPlayer(InputStream, type), native WAV playback, MIDI synthesis through SDK SDL_mixer/TiMidity with bundled Freepats, volume/mute, loop count, stop, deallocate, close, queried player state. Encoded input limited to 8 MiB/player and eight native handles. MIDI uses a temporary file under USRDIR/logs, removed on close. TiMidity uses TIMIDITY_CFG with an absolute application path. No USB or network is needed at runtime.

The PS3 SDL output is float PCM. MidiPcm.cpp wraps the SDK integer-only TiMidity Init/PlaySome functions, rendering signed 16-bit PCM into a preallocated buffer before converting to native float. prepare_audio_mixer.py rebuilds the included synthesizer in a private mixer archive, preserving the SDK archive. TiMidity is rebuilt from the included SDL_mixer 1.2.12 sources with PPU optimization; compatibility wrappers retain the SDK mixer ABI. Its configuration uses absolute instrument paths because PSL1GHT reports EINVAL for unavailable desktop directories, which stops TiMidity search. Native function bindings preserve the entire original MIDP table and add two KNI functions before JVM startup.

Validation: real ECJ Java 1.4 compile + CLDC preverify through QEMU; actual PPU compile/link; AudioSmoke runs in RPCS3 with Null renderer. WAV reached STARTED (400), naturally finished (300), then closed (0). MIDI reached STARTED (400), closed without fatal error, and increased the mixer's count of nonzero audio blocks. This proves native decoding/mixing, not audible television/HDMI sound or fidelity on the console. build/validation/audio_pkg_0103_final records the final installed-package run; earlier audio_0103_* folders retain real failed attempts.

Limits: stream players only; createPlayer(String), playTone and ToneControl remain unsupported. No MP3/AMR claim. One MIDI music stream at a time; WAV channels can overlap. Freepats is an incomplete GM instrument set. Seeking is limited to rewind; media time/duration return TIME_UNKNOWN. Stop/start restarts from the beginning. END_OF_MEDIA notifications are generated when getState polls completion; listener callbacks are synchronous, not full asynchronous MMAPI. AudioSmoke is a short WAV tone followed by one MIDI piano note. Commercial-game audio and physical console output still require testing.

Rebuild after restoring the source: fetch dependencies as in README, then run tools/integrate_audio.py --ecj /path/to/ecj-4.6.1.jar --runner /path/to/qemu-i386-static; run tools/prepare_audio_mixer.py; run tools/build_application.py --reuse-properties; package with tools/package_application.py. Source exports include adapted class library and native archive table. The source includes sound bank/license; the package builder copies it from assets/audio. No commercial game assets are included.

The locally supplied Wonder Zoo archive was also tested separately: one extracted 12,402-byte MIDI track and one 13,152-byte IMA-ADPCM WAV effect both produced hundreds of nonzero mixed audio blocks through Manager/Player. This does not test game logic scheduling or physical sound. The private test JAR and extracted game resources are excluded from the distribution; build/validation/wonder_audio contains logs only.
