# PS3ME

A native PS3 homebrew port of PS2ME, a J2ME emulator for PlayStation 2.

Current experimental snapshot: 01.14. The source archive and PKG build originate from the ongoing porting project. Version 01.14 has not been verified on PS3 hardware.

Source files, build tools, and release notes are organized in this repository.

This is an independent homebrew project, not affiliated with Sony.
